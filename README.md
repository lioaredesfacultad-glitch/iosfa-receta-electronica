# iosfa-receta-electronica
Sistema de gestion y validacion virtual de recetas medicas para IOSFA.

Descripción del proyecto

El presente proyecto propone el desarrollo de un módulo de software destinado a digitalizar la gestión y validación de recetas médicas del Instituto de Obra Social de las Fuerzas Armadas y de Seguridad (IOSFA).

La solución busca optimizar los procesos administrativos, reducir las gestiones presenciales y facilitar el acceso de los afiliados a los medicamentos mediante la implementación de recetas electrónicas.

Problemática identificada

Actualmente, los procedimientos de presentación y validación de recetas pueden generar demoras operativas, traslados innecesarios y congestión en las dependencias de atención.

Esta situación afecta especialmente a los afiliados que necesitan tratamientos continuos o tienen dificultades para trasladarse.

Objetivo general

Desarrollar e implementar un módulo de gestión y validación virtual de recetas médicas que permita digitalizar la emisión, validación y seguimiento de las prescripciones, mejorando los tiempos de respuesta y la atención de los afiliados.

Funcionalidades principales

Registro y emisión de recetas médicas digitales.

Identificación y verificación de afiliados.

Validación automática de recetas.

Control de médicos habilitados.

Consulta del estado de las recetas.

Registro y seguimiento de las prescripciones.

Integración con farmacias y prestadores habilitados.

Entidades principales de datos

Afiliado.

Médico.

Receta médica.

Validación.

Planificación del proyecto

El desarrollo se organiza en cinco etapas:

Análisis de requisitos.

Diseño del sistema.

Codificación y desarrollo.

Pruebas de calidad.

Implementación y puesta en funcionamiento.

Herramientas de gestión

Git: control de versiones.

GitHub: alojamiento del repositorio y colaboración.

GitHub Projects: seguimiento de tareas mediante metodología Kanban.

Alcance

El proyecto contempla el diseño y desarrollo de una primera versión funcional del módulo de recetas electrónicas, incluyendo la emisión, validación y consulta de prescripciones médicas.
